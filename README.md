# 暮色档案 · Dusk Archive

一本剪贴式的私人档案。把每天值得留下的片刻剪下来，贴进册子里。

## 怎么打开

双击 `index.html` 就行。不用装任何东西，也不用联网——字体、动效库、图片全在本地。

## 里面有什么

**三个视图**

- **时间流**：像微博一样往下刷的纸条，每条都能点赞、评论、收藏
- **归档**：所有纸条按时间摊成一面墙，点任意一张跳回它原来的位置
- **关于**：这本册子的来历

**能做的事**

- 点「记一笔」写新纸条（选个标签，正文随便写）
- 每条纸条下面点赞、写评论、收藏
- 右侧栏按标签或按月份筛选
- 切视图时有纸片翻页的转场

**存哪儿**

自己写的东西存在浏览器的 localStorage 里（key 是 `dusk-archive-v1`），只存在这台电脑的这个浏览器里。换浏览器或清缓存就没了——想长久留，把内容抄进 `app.js` 的 `SEED` 数组里，变成种子帖。

## 发布到网上，让别人能打开

纯静态站，不需要数据库也不需要构建。

**最快的一条路**：打开 https://app.netlify.com/drop ，把 `dusk-archive-dist` 文件夹整个拖进去，十几秒后拿到 `https://xxx.netlify.app` 的链接。注册个账号就永久保留，以后改了文件重新拖一次就更新。

**部署完记得做一件事**：把 `index.html` 里这两行的地址换成真实域名，否则微信/QQ 分享时抓不到封面图。

```html
<meta property="og:image" content="https://你的域名/og-image.jpg">
<meta property="og:url" content="https://你的域名/">
```

## 分享时会显示什么

`og-image.jpg`（1200×630）已经做好并接进 head 了。把链接发到微信、QQ、Telegram、Discord，会自动展开成一张带封面的卡片，而不是一根光秃秃的链接。

改这张卡：改 `og:title` / `og:description` 的文案；想换图就直接替换 `og-image.jpg`（保持 1200×630）。

`favicon.svg` 是标签页小图标，`apple-touch-icon.png` 是加到手机桌面的图标。

## ⚠️ 一个必须知道的限制

发帖、评论、点赞都存在**每个访客自己浏览器**的 localStorage 里。

也就是说：你部署上去以后，访客看到的是 `app.js` 里 `SEED` 那 6 条；他在页面上发的帖只有他自己能看到，你也收不到他的评论。

- 想让自己写的内容被所有人看到 → 把内容写进 `SEED` 数组，重新部署
- 想让所有人在同一个站上互相评论 → 必须加后端（Supabase 免费版可行，但那已经不是纯静态站了）

## 改内容

| 想改什么 | 改哪里 |
| --- | --- |
| 站名、导航、首页文案 | `index.html` |
| 已有的 6 条帖子 | `app.js` 顶部的 `SEED` 数组 |
| 配色 | `styles.css` 顶部的 `:root` 变量（`--ink` 夜底 / `--paper` 纸白 / `--gold` 暗金 / `--red` 朱红） |
| 配图 | 换成 `assets/` 里的同名文件即可 |

## 结构

```
dusk-archive/
├─ index.html          页面骨架
├─ styles.css          全部样式
├─ app.js              交互 + 数据 + 动效
├─ favicon.svg         标签页图标
├─ apple-touch-icon.png 手机桌面图标
├─ og-image.jpg        分享封面卡（1200×630）
├─ robots.txt          搜索引擎爬虫许可
├─ assets/             5 张配图
├─ vendor/             GSAP + 本地字体（离线可用）
└─ _shots/             成品截图
```

## 调试参数

改样式时浏览器会缓存 CSS，在后面加个 `?z=2` 之类的手动换值就能绕开。

| 参数 | 作用 |
| --- | --- |
| `?skip-gate` | 跳过开场动画 |
| `&static` | 关掉所有入场动效，直接落到终态（截图用） |
| `&view=archive` / `&view=about` | 直接进某个视图 |
| `&open=1` | 展开第一条的评论 |
| `&selftest` | 跑一遍自检，结果盖在页面左上角 |
